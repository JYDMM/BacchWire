BACCH Router

BACCH Router is a macOS virtual audio loopback driver from Theoretica Applied Physics that allows applications to pass audio to other applications with zero additional latency.

BACCH Router is a modified version of BlackHole by Existential Audio. It is free software licensed under the GNU General Public License v3 and comes with no warranty. The source code for this version is available on GitHub.

BACCH Router is free, standalone software. It is not bundled with any commercially available software.

Near the end of the installation you will be asked before the macOS audio service restarts. When it does, audio stops for a moment in all applications, so please save your work and close any audio applications first.

Features

  • Supports 44.1kHz, 48kHz, 88.2kHz, 96kHz, 176.4kHz, 192kHz and 384kHz sample rates
  • Zero additional driver latency
  • Compatible with macOS 12.4 Monterey and newer
  • Built for Intel and Apple Silicon
  • No kernel extensions or modifications to system security necessary

Earlier versions installed as "BacchWire" or "BACCHRouter" are replaced by this installer.
